# 🛒 Sistema POS & ERP Administrativo Multisucursal

Solución integral de punto de venta (POS), control de inventario en tiempo real, gestión financiera multidivisa y tienda online para operaciones de una o múltiples sucursales con soporte 100% Offline.

---

## 🌟 Características Principales
- 💳 **Punto de Venta (POS):** Facturación multidivisa (USD / Bs), pagos combinados (efectivo, débito, Pago Móvil), tickets en espera (Hold) e impresión térmica 58/80mm.
- 🏢 **Multisucursal & Stock:** Control centralizado de inventario, stock mínimo y carga de facturas de compras.
- 💰 **Finanzas:** Cuentas por Cobrar (CxC), Cuentas por Pagar (CxP) y Cortes Fiscales de Caja X y Z.
- 🛍️ **Tienda Online:** Catálogo e-commerce integrado con recepción directa de pedidos.
- 🛡️ **Auditoría & Licencias:** Bitácora inmutable con IP y protección de licencias.
- ⚡ **Modo Offline:** Generador de ejecutable único .HTML autónomo.
